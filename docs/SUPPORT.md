# Getting help

DaasaVaani is in planning/pre-implementation. A placeholder website is not an
available lyrics product, and there is no established application support window.

## Where to ask

- Read the [project README](../README.md), [requirements](requirements.md), and
  [documentation index](README.md) first.
- Search [existing issues](https://github.com/DaasaVaani/DaasaVaani.github.io/issues).
- Open a bug report for reproducible problems or a feature request for proposals.
- For general questions, open a clearly titled issue explaining what you tried.
- For lyrics, transliteration, or attribution corrections, include the lyric ID
  (or the legacy fixture/video reference when applicable),
  affected script/field, and proposed correction with supporting information.
  Do not reproduce material you lack permission to share.

Include the relevant version/commit, browser or Android version, steps,
expected/actual results, and sanitized logs/screenshots where applicable.
There is no guaranteed response time, delivery date, or commercial support.

## Sensitive matters

- Vulnerabilities and leaked secrets: [security policy](SECURITY.md).
- Abuse and harassment: [Code of Conduct](CODE_OF_CONDUCT.md).
- Ownership/permission concerns: [content rights](https://github.com/DaasaVaani/library/blob/main/docs/content-rights.md).

Do not put credentials, personal data, or confidential evidence in public issues.
